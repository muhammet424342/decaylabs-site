# Discord implementation blueprint — Deferred / Not Active

> Legacy planning asset. The 2026 Farcaster audit found no verified holder community that needs Discord yet. Do not create or promote this server until recurring collectors/users need a persistent support or lore space. Empty channels would reduce trust. Retained for reference; not an active operating plan.

Do not publicly promote the server until every item in the launch gate is complete.

## Roles

- `Founder`: one account only; hardware-backed 2FA.
- `Archivist`: moderators and lore operators; no administrator permission by default.
- `Verified Witness`: wallet-verified holder role.
- `Field Researcher`: active non-holder contributor earned through participation, never purchased.
- `Faction — Rustbound / Sporekin / Glass Saints / Staticborn / Bone Cartographers`: self-selected lore roles.
- `New Arrival`: default role with limited link/embed permissions.
- `Bots`: isolated role below moderators, minimum permissions.

## Onboarding message

`Welcome to Vanta.`

`Decay Labs is a story-first archive of 1,000 altered witnesses on Base. Start with #rules-and-safety, verify every link in #official-links, then choose the faction whose theory of decay you trust most.`

`No moderator will DM first. No surprise mint exists. Never sign a transaction sent through a private message.`

## Weekly rituals

- Monday — `Archive Briefing`: what shipped, what did not, what is next.
- Tuesday — `Subject Autopsy`: one token, its visual evidence and memory fragment.
- Thursday — `Theory Lab`: one unresolved lore question with a 24-hour debate.
- Friday — `Build Log`: screenshot, commit or working prototype—not a promise.
- Sunday — `Vanta Radio`: 30-minute X Space/Discord stage with a written recap.

## Holder activity without financial theatre

- Let holders nominate their Subject for a future archive entry.
- Award profile badges for theories, art, translation and moderation help.
- Use canon checkpoint votes only at chapters 10, 20, 30…100.
- Publish a decision record showing options, result and exact story consequence.
- Feature collectors through consent-based interviews; never imply purchase guarantees influence.
- Run small art/lore challenges with fixed, disclosed rewards.

## Safety configuration

1. Require 2FA for moderation actions.
2. Disable `@everyone` mentions for non-staff.
3. Set new arrivals to restricted embeds and links.
4. Enable AutoMod for seed phrases, “support ticket” impersonation, mass mentions and common drain domains.
5. Keep official links read-only.
6. Log role, channel and webhook changes.
7. Use a wallet-verification provider only after reviewing requested permissions; verification must never require a transaction.
8. Publish incident language before an incident occurs.

## Public launch gate

- Two human moderators in different time zones.
- Rules, official links, verification guide and FAQ are complete.
- Scam-report route tested.
- Holder verification tested with a non-founder wallet.
- Seven days of scheduled programming prepared.
- First `Vanta Radio` time announced.
