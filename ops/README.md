# Decay Labs Growth Operating System

This directory turns the strategy into repeatable execution. Public copy is written in English because Decay Labs is positioned as an international brand; operator notes remain concise and unambiguous.

## Source of truth

- `x/profile-and-pinned.md`: exact X profile copy and pinned launch thread.
- `x/30-day-calendar.md`: one ready-to-publish post per day, with art and timing.
- `x/100-post-ideas.md`: reusable growth inventory grouped by content job.
- `x/reply-system.md`: daily relationship-building workflow and response bank.
- `community/discord-setup.md`: server architecture, roles, rituals and safety.
- `marketplace/opensea-profile.md`: marketplace copy and inventory release policy.
- `90-day-execution.md`: weekly operating plan, owners, outputs and gates.
- `external-actions.md`: changes that need an authenticated account, wallet signature or third-party approval.

## Non-negotiables

1. Never claim fake rarity, volume, demand, sell-outs, partnerships or roadmap delivery.
2. Never use engagement bots, bought followers, reply spam or undisclosed paid shilling.
3. Every sales post must include story, provenance or collector context—not price alone.
4. Publish consistently in UTC-friendly English; reply like a human, not a campaign account.
5. Treat game, staking, AI and tools as experiments until a working artifact exists.
